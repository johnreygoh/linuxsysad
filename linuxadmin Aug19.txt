all = 7

//symbolic
u = owner
g = group
o = others
a = all

+/- rwx

//change ownership

filesystem structure (review)

bin	essential commands, ls, cp, cat
boot	kernel, bootloaders
dev	device (hard drives, usb, null)
etc	system-wide configuration (passwd,groups,shadow,sshd_config)
home	user home folder
lib,lib64	shared libraries, functions
media	"ready-to-use" mount point for removable storage (CD,DVD,USB)
mnt	temporary mount point (folder<---partition)
opt	optional software (3rd party apps)
proc	virtual filesystem, process and kernel info
root	home directory of root
run	runtime process data (/var/run, volatile), usually for services
sbin	system binaries for config system (shutdown,fdisk)
srv	data for system services
sys	virtual filesystem, devices and kernel info,stats and *config
tmp	temporary folder (auto-delete upon reboot)
usr	user applications and tools
var	variable (logs,web)


disk partitions and file system

storage device (raw) -> /dev -> partition + format (filesystem) -> mount 

windows:
FAT
NTFS

linux:
ext2 	old, no journaling, risky on crashes
ext3	adds journaling (safer on crashes)
ext4 	most common debian-based, debian/ubuntu

xfs	def in rhel,centos,OL, journaling, large files & parallel I/O
	(cannot shrink an xfs partition)

B-Tree FS (btrfs)
-common openSUSE,fedora
-flexible partition (grow and shrink)
-snapshots, compression, check data integrity


ZFS (openZFS)
-solaris, volume manager, high ram usage

partitioning and formatting a raw drive

1. list all detected drives
lsblk
lsblk -f

2. creating new partition (fdisk,gparted(GUI))
//select disk
sudo fdisk /dev/sdb

commands
n - new part
	n > p > part# > firstsector? > lastsector? +2G
p - print part table
w - save changes

//refresh  partition list
sudo partprobe

//format partition
sudo mkfs.ext4 /dev/sdb2
sudo mkfs.xfs /dev/sdb1

//make folder for the partitions
sudo mkdir /mnt/partition1
sudo mkdir /mnt/partition2

//temporary mount (disconnects after reboot)
sudo mount /dev/sdb1 /mnt/partition1
sudo mount /dev/sdb2 /mnt/partition2

df -h | grep /mnt/parti


//permanent mount (persist across reboots)
//edit fstab
//note the UUID sdb
├─sdb1   xfs                        71dc5403-0287-421e-9973-3f67252d57f0      1.9G     2% /mnt/partition1
└─sdb2   xfs                        c2abaea0-95ec-43cd-8757-ab4ddc8a0f1f      1.9G     2% /mnt/partition2

//add in fstab
UUID=71dc5403-0287-421e-9973-3f67252d57f0 /mnt/partition1 xfs defaults 0 0
UUID=c2abaea0-95ec-43cd-8757-ab4ddc8a0f1f /mnt/partition2 xfs defaults 0 0

//reload fstab
sudo mount -a

//unmount a partition
sudo umount /mnt/partition1
